# 内购挑选助手

一个用来处理每月内购商品清单的浏览器小工具。导入 Excel 后，可以按品牌、类型、价位和预算筛选商品，加入购物车或候选清单，最后复制订购单、下载 CSV，或者导出分享图，方便自己挑选，也方便和同事一起核对。

## 主要功能

- 导入 `.xlsx`、`.xls`、`.csv` 商品清单
- 自动识别商品名、品牌、规格、价格、库存、图片等字段
- 自动合并重复商品，并在导入检查里提示合并数量
- 导入后检查异常：缺品牌、缺价格、缺图片、库存未知、分类为“其他”
- 异常检查支持一键定位问题商品
- 自动保存最近一次商品清单，刷新或重新打开后可以继续上次进度
- 更换新清单时自动核对上次购物车，提示价格、库存和下架变化
- 支持多关键词搜索，例如 `徽章 不鸭 -贴纸`
- 按品牌、类型、价位、预算筛选商品
- 常用品牌可以星标置顶
- 支持奶油柔和、浅色、深色三种配色
- 支持紧凑、舒适、大图三种卡片密度
- 三栏宽度可以拖动调整，也可以一键恢复默认布局
- 商品可以加入购物车、候选清单和对比小桌
- 候选商品支持“二选一”淘汰赛，逐轮选出最终赢家
- 购物车按品牌分组，并支持一键折叠/展开品牌组
- 购物车显示类型花费结构、低库存和同类省预算提醒
- 预算方案的单件价位、IP 品牌和商品类型均可多选，并会实时重新计算
- 贴额、品类均衡、偏爱优先三套组合都会优先靠近剩余额度
- 「试试手气」支持从当前结果、全部商品或候选清单随机 Roll 一件
- 输入生日月日可以生成每月固定的星座幸运商品，生日不会保存
- 预算扭蛋可以按金额随机生成 `1–5` 件不超预算的组合
- 预算浮窗支持胶囊模式、展开查看、拖动位置
- 支持复制订购单、下载正式 Excel、下载 CSV、导出分享图
- 导出前可以填写部门和内购人姓名，填写一次后会保存在当前浏览器
- 复制到 Excel 或 WPS 时自动合并总额、部门和姓名对应的商品行
- Excel 导出直接从十列表头开始，商品编号按文本完整显示
- 支持自定义分类关键词，方便每月新清单继续复用
- 基础分类规则使用独立版本包，方便统一更新
- Excel 读取和分享图组件随网页一起托管，不依赖公共 CDN
- 支持手机端/窄屏浏览，底部有快捷入口
- 左栏依次排列导入清单、预算与筛选、导出订单；外观与高级设置默认收起
- 品牌、类型、价位独立展开，收起后仍显示已选条件
- 右栏依次显示购物车、候选清单、商品对比和预算建议，预算分析可单独展开
- 候选与对比首次加入商品时自动展开，手动收起后保留数量提示；清空后自动收起
- 购物车商品信息与数量操作分行排列，窄栏及手机抽屉均可完整操作
- 第一次打开会自动显示聚光式使用教程，并可在左栏底部或版本说明中重新查看

## 怎么使用

1. 打开网页，第一次使用时可以跟随页面教程快速认识主要功能。
2. 点击左侧「选择文件」。
3. 选择本月的商品清单 Excel 或 CSV 文件。
4. 如果浏览器里有上次购物车，先在核对弹窗中选择保留可匹配商品或清空购物车。
5. 查看导入检查弹窗，必要时点击「定位」查看问题商品。
6. 在「预算与筛选」填写预算，按需展开品牌、类型和价位进行多选，下方可调整排序与浏览模式。
7. 点击商品卡片空白处加入购物车，暂时不确定的可以先放进候选清单。
8. 候选较多时，可以在候选清单中点击「二选一」逐轮筛选。
9. 想快速凑预算时，可以点击页面顶部的「预算方案」，多选单件价位、IP 品牌和商品类型，再设置最多款数后选择整套组合。
10. 想轻松一点时，可以打开「试试手气」，随机 Roll、本月幸运或用预算扭蛋生成组合。
11. 选好后，在「导出订单」里复制订购单、下载 Excel 或下载 CSV；确认时可以填写部门和内购人姓名。
12. 如果需要发给别人确认，可以展开「分享图」，填写署名并导出分享图；「订单文本预览」可单独展开。

配色、卡片密度和重置布局集中在左栏下方的「外观设置」；列映射、分类维护和清理数据集中在「高级设置」。这些设置默认收起，使用教程入口位于左栏最底部。

右侧「购物车」始终展开，直接查看合计与剩余预算；「候选清单」「商品对比」「预算建议」可以分别展开。预算结构与替代提醒在「预算分析」中查看，手机购物车抽屉也支持单独展开。

## 搜索技巧

搜索框支持多个关键词，用空格隔开。

```text
徽章 不鸭
```

表示同时包含“徽章”和“不鸭”。

```text
徽章 -贴纸
```

表示包含“徽章”，但排除包含“贴纸”的商品。

## 数据和隐私

这个工具是纯前端网页，商品清单会在浏览器本地读取和处理。

也就是说：

- 导入的 Excel 不会自动上传到服务器
- 最近一次整理后的商品清单会保存在当前浏览器的本地数据库中，用于刷新后恢复进度
- 购物车、候选清单、预算、主题、常用品牌、自定义分类等偏好会保存在当前浏览器本地
- 换电脑或换浏览器后，本地保存的数据不会自动同步
- 如果页面状态异常，可以在「高级设置」里点击「清理本机数据」恢复默认状态

## 文件说明

```text
index.html
```

网页主文件。GitHub Pages 会默认读取这个文件作为首页。

```text
classification-rules.js
```

统一分类规则包。每月补充公共分类关键词时主要更新这个文件，并同步修改 `index.html` 中规则文件的网址版本参数。

```text
vendor/
```

网页使用的 Excel 读取组件、分享图组件和对应开源许可证。不要单独删除。

```text
内购挑选助手_v68_右栏层级整理版.html
```

当前版本的完整备份文件，方便保留版本记录。

## 发布和更新

这个项目可以直接用 GitHub Pages 托管。

更新网页时，需要一起提交 `index.html`、`classification-rules.js` 和 `vendor` 目录。GitHub Pages 会自动重新部署。

当前版本已经加入页面版本检查。新版发布后，网页会尽量自动绕开浏览器缓存加载最新版本。如果仍然看到旧页面，可以尝试刷新一次，或者在网址后加一个版本参数，例如：

```text
?v=68
```

## 常见问题

### 导入 Excel 后图片不显示

图片能否显示取决于清单里的图片链接是否允许外部访问。如果原图链接需要登录、过期了，或者禁止外部网页读取，就可能无法显示。

### 分类不准确怎么办

可以展开左栏下方的「高级设置」，在「分类维护」里给未识别商品补充关键词。补充后的关键词会保存在当前浏览器本地，下次导入清单时继续生效。

### 页面状态乱了怎么办

可以在「高级设置」里点击「清理本机数据」。这会清空当前浏览器保存的最近清单、购物车、候选清单、预算、主题、常用品牌和自定义分类。

## 界面回归检查

安装 Node.js 和 Playwright 后，运行 `node tests/sidebar-layout.cjs`。测试使用无界面的 Microsoft Edge，检查桌面三栏、平板两栏（含 260px 窄侧栏）和手机布局，以及导入、筛选、预算、导出预览、配色切换和教程定位。

运行 `node tests/rightbar-layout.cjs` 检查右栏 260px、320px、460px 宽度、平板及手机抽屉，以及购物车数量、撤销、候选转加购、对比、折叠行为与三种配色。

## 适合谁用

适合每月面对一大张内购商品清单、需要控制预算、筛选品牌、整理订购单的人使用。

尤其适合：

- 自己慢慢挑
- 和同事一起核对
- 给朋友发一张确认图
- 每月复用类似格式的商品清单
